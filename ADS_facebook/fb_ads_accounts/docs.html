Facebook Ads Pipeline

Hệ thống tự động lấy dữ liệu quảng cáo Facebook qua Meta Graph API v20.0 và ghi vào Google Sheets theo cấu trúc cây Campaign → Adset → Ad.

Kiến trúc hệ thống

main.pyPhase 0

Lấy danh sách tài khoản quảng cáo từ Meta API và ghi vào sheet TKQC API.

Người dùng đánh TRUE vào cột Chọn Lấy Camp để chọn tài khoản cần theo dõi.

get_campaigns.pyPhase 1

Lấy danh sách campaign của các tài khoản được chọn và ghi 1 dòng/campaign vào tab tài khoản, kèm metrics tháng này.

Người dùng đánh TRUE vào Chọn Lấy Chi Tiết để chọn campaign xem chi tiết.

get_details.pyPhase 2

Mở rộng các campaign được chọn thành cây Campaign → Adset → Ad, kèm creative và metrics cấp Ad.

Import toàn bộ shared code từ get_campaigns.py.

ℹ️
Dependency: get_details.py import từ get_campaigns.py. Cả hai file phải nằm cùng thư mục. main.py độc lập hoàn toàn.

Quy trình chạy

0
Chạy python main.py
Lấy danh sách tất cả tài khoản quảng cáo trong Business Manager → ghi vào sheet TKQC API. Đánh TRUE vào cột Chọn Lấy Camp cho tài khoản muốn theo dõi.
1
Chạy python get_campaigns.py
Với mỗi tài khoản được chọn: gọi API lấy campaigns + insights tháng này → ghi mỗi campaign thành 1 dòng vào tab tài khoản. Cột Chọn Lấy Chi Tiết được giữ nguyên. Đánh TRUE vào campaign muốn xem chi tiết.
2
Chạy python get_details.py
Với các campaign được chọn: gọi API lấy adsets, ads, creative, insights cấp Ad → ghi lại toàn bộ sheet theo cây Campaign → Adset → Ad.
↻
Lặp lại hàng ngày / theo lịch
Chạy Phase 1 hàng ngày để cập nhật metrics. Chạy Phase 2 khi cần xem chi tiết creative hoặc hiệu quả từng Ad.

get_campaigns.py — Phase 1: Danh sách Campaign

Ghi danh sách campaign kèm metrics tháng này vào tab tài khoản. Các module khác import constants và shared functions từ file này.

⚡ Import hub: get_details.py import toàn bộ shared code từ file này. Không xóa hoặc rename hàm public.

Hàm Facebook API

Hàm Metrics

parse_insight_metrics(insight: dict) → dict
Chuyển raw insight API thành dict chuẩn hóa (float). Tự tính CTR/CPC/CPM/freq nếu API không trả về. Bao gồm: spend, impr, clicks, ctr, cpc, cpm, reach, freq, inbox, cpi, leads, cpl, purchases, cps, revenue, roas, ket_qua, cpkq.
aggregate_metrics(metrics_list: list[dict]) → dict
Tổng hợp metrics từ nhiều Ad để tính Adset tổng. Sum các giá trị thô (spend, impr, clicks, reach, inbox, leads, purchases, revenue, ket_qua), tính lại tỷ lệ. Dùng trong get_details.py.
_get_primary_result(insight: dict) → tuple[float, float]
Xác định "Kết Quả" chính bằng cách dùng cost_per_action_type (API tính sẵn) theo thứ tự ưu tiên RESULT_TYPES. Trả về (ket_qua_count, chi_phi_ket_qua).

Bóc creative_id, page_id, post_id, body, title, description, link, cta, thumbnail_url từ object_story_spec. Post ID lấy từ phần sau _ của effective_object_story_id.

Hàm Row builders

Dòng Ad — đầy đủ creative (I–Q), metrics cấp ad.
build_rows(campaigns, camp_insights_map, adset_data_map, ad_insights_map, detail_selections, currency, now_str) → list[list]
Xây toàn bộ danh sách dòng. Với campaign KHÔNG được chọn: chỉ có 1 dòng Campaign. Với campaign được chọn: 1 Campaign + N×(1 Adset + M×Ad). Sắp xếp: ACTIVE trước, rồi theo tên.

Luồng main() của get_details.py

1

2

Không tốn API call.
3

Cần để vẽ toàn bộ cây (cả campaign không được chọn cũng cần có dòng).
4

Ghi đè toàn bộ sheet. Lưu adsets.json, ads.json, insights_ad.json.

Logic xác định "Kết Quả"

ℹ️ Facebook Ads Manager hiển thị "Kết quả" dựa trên optimization_goal của adset. Vì API không trả về optimization_goal trong insights, chúng ta xấp xỉ bằng cách dùng cost_per_action_type (đã được Facebook tính sẵn) theo thứ tự ưu tiên RESULT_TYPES. 
# Thứ tự ưu tiên:
RESULT_TYPES = INBOX_TYPES + LEAD_TYPES + PURCHASE_TYPES + [
    "post_engagement", "page_engagement", "link_click",
    "video_view", "app_install"
]

# Tìm action_type đầu tiên có cost > 0 trong RESULT_TYPES
for atype in RESULT_TYPES:
    cpx = cost_map.get(atype, 0.0)
    if cpx > 0:
        return action_map.get(atype, 0.0), cpx

Adset metrics — cách tổng hợp

Không có API call cấp adset. Adset metrics được tính bằng cách sum ad-level metrics trong Python.

ad_metrics_list = [parse_insight_metrics(ad_insights_map.get(ad_id, {})) for ad in sorted_ads]
adset_m = aggregate_metrics(ad_metrics_list)

Các giá trị thô (spend, impr, clicks, reach, inbox, leads, purchases, revenue, ket_qua) được cộng lại. Tỷ lệ (CTR, CPC, CPM, freq, CPI, CPL, CPS, ROAS, cpkq) được tính lại từ các giá trị tổng.
