GetTextFromLink — Bản CPU

Dùng trên Windows 10/11 64-bit (Intel/AMD). Không cần cài Python, FFmpeg hoặc driver NVIDIA. Bộ cài đã kèm model large-v3-turbo.

Cài đặt và sử dụng

  1. Chạy GetTextFromLink-Setup-1.0.0-CPU-x64.exe, bấm Next → Install → Finish.
  2. Mở biểu tượng GetTextFromLink trên Desktop.
  3. Dán danh sách link hoặc chọn file video/âm thanh trên máy. Giữ model large-v3-turbo để dùng model có sẵn.
  4. Giữ tùy chọn bỏ qua GPT nếu chỉ cần lấy nội dung. Bấm bắt đầu và chờ nhận diện. CPU có thể xử lý lâu với video dài.
  5. Xem tab nội dung Word hoặc xuất kết quả từ giao diện.

Dữ liệu và kết quả

Nhấn Windows + R, nhập %LOCALAPPDATA%\GetTextFromLink để mở thư mục dữ liệu. File kết quả mặc định là final_result.docx; lỗi khởi động được ghi vào application.log. Cũng có thể mở “Thu muc ket qua” trong Start Menu.

Cài lại hoặc gỡ phần mềm sẽ giữ dữ liệu trong thư mục này. Nên có ít nhất 8 GB RAM và khoảng 6 GB đĩa trống cho cài đặt, cộng dung lượng video cần xử lý.

Internet, Firefox và model khác

Nhận diện file có sẵn bằng model mặc định không cần Internet. Tải video từ link, tải model khác và dùng ChatGPT cần Internet. Website có thể yêu cầu đăng nhập hoặc giới hạn tải video.

Nếu muốn dùng ChatGPT: cài Firefox, mở lại ứng dụng, mở Firefox từ ứng dụng và đăng nhập ChatGPT trong cửa sổ đó. Phần mềm sử dụng hồ sơ Firefox riêng trên máy mới. Cookie, tài khoản và dữ liệu của máy tạo bộ cài không được chuyển sang.

Link cần đăng nhập Facebook hoặc website khác: đăng nhập bằng Firefox trên máy mới. Mặc định công cụ tải đọc cookie từ Firefox. Các model khác sẽ tự tải khi chọn lần đầu và cần thêm dung lượng đĩa.
